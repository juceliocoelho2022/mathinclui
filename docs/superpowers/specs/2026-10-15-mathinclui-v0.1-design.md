# MathInclui v0.1 — Design Técnico

**Data:** 2026-10-15
**Status:** aprovado

## Visão
O MathInclui é um sistema educacional para apoiar estudantes com diferentes necessidades de aprendizagem em Matemática. O sistema trabalha com necessidades pedagógicas observáveis e configurações de apoio definidas pelo professor, sem armazenar laudos ou diagnósticos clínicos.

## Arquitetura
Monólito modular Spring Boot/Java 21, frontend React/TypeScript e PostgreSQL com Flyway.
